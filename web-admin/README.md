# 🛠️ Urban Bites Admin Portal (`web-admin`)

Окремий веб-застосунок адміністратора та менеджера мережі закладів Urban Bites (Urban Pizza & Sushi, Urban Bakery & Coffee, Urban Club).

---

## ⚡ Можливості

• 📊 **Дашборд бізнес-аналітики:**
  ▫️ Виторг, динаміка замовлень за періодами (день, тиждень, місяць).
  ▫️ Розподіл замовлень за закладами, способами доставки та типами оплати.
  ▫️ Топ страв за продажами та сумою.

• 📋 **Керування та моніторинг замовлень:**
  ▫️ Живий перегляд статусів замовлень у реальному часі.
  ▫️ Швидка зміна статусів (готується, на доставці, виконано тощо).
  ▫️ Редагування складу замовлень, адрес доставки та контактів клієнтів.

• 🍕 **Керування меню, стравами та стоп-листом:**
  ▫️ Категорії та підкатегорії з автосортуванням.
  ▫️ Модифікатори, розміри та цінові сітки.
  ▫️ Стоп-лист страв у реальному часі.

• 👥 **Користувачі та персонал:**
  ▫️ База клієнтів, баланс бонусів Urban Club, блокування та нотатки.
  ▫️ Керування персоналом (менеджери, адміністратори, PIN-коди для POS).

• 📢 **Маркетингові розсилки:**
  ▫️ Таргетовані розсилки у Telegram за сегментами аудиторії з live preview.

---

## 🛠️ Стек технологій

- **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS v4, TanStack Query v5
- **Мережа:** REST API до FastAPI (`/urban-bites/api/`)
- **Docker:** порт `5178` (проксується Caddy на `https://nikiga-ax.duckdns.org/urban-bites/admin/` та локально)

---

## 🚀 Запуск та розробка

```bash
# Збірка
npm run build

# Локальний dev-сервер
npm run dev -- --host 0.0.0.0 --port 5178
```
