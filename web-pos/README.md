# 📟 Urban Bites POS Portal (`web-pos`)

Веб-застосунок робочого місця касира та офіціанта (Point of Sale) для мережі ресторанів **Urban Bites** (м. Вишгород).
Оптимізований для планшетів, ноутбуків і мобільних телефонів (iOS Safari, Android).

---

## ⚡ Можливості

• 🔒 **Швидка авторизація співробітників:**
  ▫️ Вибір офіціанта/бармена зі списку активного персоналу.
  ▫️ 4-значний PIN-код для миттєвого входу та блокування терміналу в один клік.

• 🍽️ **Розділення логіки обслуговування:**
  ▫️ **В закладі (`dine_in`):** вибір номера столу (`1-6`, `Бар` або довільний номер). Замовлення відправляється на кухню без передоплати зі статусом `payment_method = 'pending'` та `is_paid = false`.
  ▫️ **З собою (`pickup`):** миттєва оплата готівкою (`cash`) або карткою (`card`).

• 📋 **Керування відкритим столом та кухнею:**
  ▫️ **Поштучне відмічання подачі страв:** офіціант може відмічати кожну винесену страву окремо (`[⬜ Подати] / [✓ Подано]`).
  ▫️ **Динамічне дозамовлення:** кнопка `➕ Дозамовити` на картці столу повертає в меню в режимі дозамовлення — нові позиції додаються до поточного рахунку столу та сповіщають кухню.
  ▫️ **Розрахунок столу при закритті:** кнопка `💳 Розрахувати стіл` відкриває модальне вікно для вибору типу оплати (готівка/термінал) та списання балів програми лояльності Urban Club.

• 💰 **Касові зміни та звітність (X/Z-звіти):**
  ▫️ **Відкриття зміни:** внесення початкової розмінної суми готівки при відкритті зміни касиром.
  ▫️ **Службові операції з готівкою:** внесення (розмін) та винесення (інкасація/витрати) з обов'язковою фіксацією причини в аудит-лозі.
  ▫️ **X-звіт у реальному часі:** живий підрахунок очікуваної готівки в шухляді, виторгу готівкою, безготівкою (картками), списаних бонусів та кількості замовлень.
  ▫️ **Z-звіт та закриття зміни:** введення фактичного залишку готівки, розрахунок надлишку / нестачі, архівування зміни та миттєва відправка фінансового звіту керівництву в Telegram.

• ✏️ **Редагування позицій та скасування чеків:**
  ▫️ **Швидка зміна кількості:** степери `[ − ] [ qty ] [ + ]` прямо на кожній позиції відкритого чеку з миттєвим перерахунком підсумку.
  ▫️ **Поштучне видалення:** видалення помилкової страви `[ 🗑️ ]` з чеку з автооновленням вартості.
  ▫️ **Повне скасування чеку (`[ ❌ Скасувати ]`):** обов'язковий вибір швидкої причини або введення довільного тексту, автоповернення списаних бонусів клієнту та надсилання аудиту скасування в Telegram керівництву.

• 🔔 **Звукові сповіщення та автооновлення:**
  ▫️ **Синтезовані аудіо-сигнали:** чистий поліфонічний передзвін на базі Web Audio API (без завантаження зовнішніх аудіофайлів) для подій «Нове замовлення» та «Страва готова на кухні».
  ▫️ **Перемикач звуку:** кнопка швидкого увімкнення / вимкнення звуку (`🔔` / `🔕`) у верхній панелі із запам'ятовуванням у `localStorage`.
  ▫️ **Фоновий періодичний автоапдейт:** тихе опитування замовлень та статусу каси кожні 10 секунд без перезавантаження сторінки.

• 🎛️ **Гнучкі модифікатори та безкоштовні квоти:**
  ▫️ Керування кількістю кожної опції за допомогою степера `[ − ] [ к-сть ] [ + ]`.
  ▫️ Автоматичне підтягування обов'язкових та безкоштовних модифікаторів (васабі, імбир, прибори, соуси за замовчуванням).
  ▫️ Розрахунок безкоштовної квоти (`free_count`) на фронтенді та бекенді.

• 📱 **Мобільний UX:**
  ▫️ Поле пошуку клієнта за номером телефону відкриває суто числову клавіатуру на смартфонах (`type="tel"`, `inputMode="numeric"`).
  ▫️ Підняті плашки кнопок чека з урахуванням iOS Safe Area (`env(safe-area-inset-bottom)`).

## 🛠️ Стек технологій

- **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS v4, Web Audio API
- **Мережа:** REST API до FastAPI (`/urban-bites/api/pos/`)
- **Docker:** порт `5177` (проксується Caddy на `https://nikiga-ax.duckdns.org/urban-bites/pos/` та `http://pos.lan`)
